# متجر Z الجديد

بداية جديدة لمتجر الويب باستخدام Next.js وTypeScript وSupabase. الموقع الحالي في D:\Business\Z-web لم يتم تعديله، وقاعدة بيانات Supabase لم تتغير.

## الموجود حاليًا

- واجهة متجر عربية RTL بتصميم متجاوب للجوال والكمبيوتر.
- جلب المنتجات المفعّلة من جدول products في مشروع Supabase المستخدم بتطبيق Z.
- ألوان التطبيق الداكنة: فحمي، أبيض، وأزرق iOS.
- شريط الإعلان وفيديو الإعلان بعرض الشاشة، مع جلب النص واللون والحجم ورابط الفيديو وحالة التفعيل من `siteSettings/home`.
- صفحة تفاصيل لكل منتج مع صور متعددة، المقاسات والألوان، البطارية والمساحة، التقييمات، والسعر.
- البحث والتصفية حسب القسم، المنتج المميز، المفضلة، السلة، تسجيل الدخول وإنشاء الحساب واستعادة كلمة المرور.
- إتمام الطلب بالدفع عند الاستلام بنفس الحقول الأساسية في التطبيق، وصفحة طلباتي وتتبع الحالة.
- صفحات `/admin` و`/seller` لعرض الطلبات وتغيير حالتها باستخدام RPCs المحمية الموجودة أصلًا في قاعدة البيانات.
- لا توجد مفاتيح سرية أو خدمة service_role في الموقع. المفتاح المستخدم هو مفتاح النشر العام نفسه الموجود بالتطبيق.
- لا توجد ترحيلات أو تغييرات مطلوبة على قاعدة البيانات.

## التشغيل

من PowerShell:
- انتقل إلى C:\Users\Moamen\Desktop\Z-web-new
- شغّل npm install
- ثم شغّل npm run dev

إعدادات Supabase موجودة محليًا في .env.local، وملف .env.example يوضح القيم اللازمة عند نقل المشروع. لا ترفع .env.local إلى Git.

## النشر على Cloudflare

المشروع يستخدم مسارات Next.js ديناميكية، لذلك يُنشر كتطبيق Cloudflare Worker عبر OpenNext، وليس كمجلد `dist` ثابت.

- جهّز بيئة Linux أو WSL وثبّت الحزم باستخدام `npm ci`.
- أنشئ ناتج Cloudflare باستخدام `npm run cf:build`؛ الملفات الجاهزة ستظهر في `.open-next`.
- شغّل معاينة محلية باستخدام `npm run preview`.
- بعد ربط Wrangler بحساب Cloudflare، انشر باستخدام `npm run deploy`.
- أضف متغيرات Supabase الموجودة في `.env.example` إلى إعدادات Worker، ولا ترفع `.env.local`.

ملاحظة: بناء OpenNext على Windows قد يفشل بسبب قيود توافقه المعلنة؛ استخدم WSL أو بناء Cloudflare Workers من بيئة Linux.

## ما يحتاج استكمالًا قبل اعتباره مطابقًا لكل لوحة التطبيق

- إدارة المنتجات بالكامل (إضافة وتعديل وحذف ورفع الصور) وإدارة بيانات البائعين والاشتراكات والمشرفين.
- لوحة مؤشرات الإدارة، قوالب الإشعارات وإعداد صوتها، وإدارة إعدادات المتجر من الويب.
- اختبار التحقق من البريد وإعادة كلمة المرور وتدفق الطلب على نطاق نشر حقيقي.

## الفحص

- `npm run build`: نجح، بما فيه TypeScript وإنشاء صفحات الموقع.
- ESLint: لا توجد أخطاء؛ بقيت تحذيرات تحسين الصور من استخدام `<img>`.
- لم يمكن اختبار الاتصال الحي بـ Supabase أثناء البناء لأن الشبكة إلى المشروع محجوبة في بيئة الفحص. لذلك يلزم فتح الموقع من الجهاز والتحقق من قراءة البيانات، ووجود سياسات RLS المناسبة، وضبط روابط Auth على نطاق الموقع قبل النشر.
